1. Word Embeddings

Key idea. Replace atomic one-hot $\mathbf{e}_w\in\{0,1\}^{|V|}$ (always orthogonal) with dense $\mathbf{e}_w\in\mathbb{R}^d$, $d\ll|V|$, so geometry encodes meaning. Foundation: distributional hypothesis — words in similar contexts have similar meanings.

Word2Vec. CBOW: predict center from averaged context. Skip-gram: predict each context word from center (more updates for rare words). Negative sampling: $|V|$-softmax → $k$ binary classifications, $O(k)$ vs $O(|V|)$.

GloVe. Factorizes log co-occurrence $X_{ij}$: $J=\sum f(X_{ij})(w_i^\top\tilde w_j+b_i+\tilde b_j-\log X_{ij})^2$. Weight $f$ damps very frequent pairs.

Why it works. Linear analogies $\mathbf{e}_{\text{king}}-\mathbf{e}_{\text{man}}+\mathbf{e}_{\text{woman}}\approx\mathbf{e}_{\text{queen}}$ — meaning in differences. W2V implicitly factorizes shifted PMI; GloVe explicitly factorizes log-counts.

Left open. Static — one vector per word-type ⇒ polysemy ("bank"). CBOW averaging destroys word order.

Can smoothing make one-hot similar for synonyms? No — smoothing redistributes mass; it cannot create similarity over atomic symbols.

2. Fixed-Context LMs: n-grams

Key idea. Markov truncation of history: $P(w_t\mid w_{1:t-1})\approx P(w_t\mid w_{t-n+1:t-1})$, MLE counts $\hat P=C(\text{ctx},w)/C(\text{ctx})$.

Eval. Perplexity $PP(W)=P(W)^{-1/N}$ = exponentiated avg NLL.

Smoothing. Laplace (add-$\alpha$); Kneser–Ney uses continuation probability — how many distinct contexts a word appears in, not raw frequency.

Issues. (i) Sparsity of high-order n-grams; (ii) no cross-word generalization (cat/dog are atoms); (iii) hard context cap at $n{-}1$.

Next step. Neural LMs share embedding parameters ⇒ similar words get similar predictions even without co-occurring.

Why can't even perfect smoothing generalize across synonyms? No distributed representation: each word is atomic; smoothing moves mass, never creates similarity structure.

3. Neural LMs: RNN & LSTM

RNN. Same $W_h,W_x$ at every step:

h_t = tanh(W_h · h_{t-1} + W_x · x_t + b)
P(w_{t+1}) = softmax(W_out · h_t)
x_t:(B,d)   h_t:(B,h)

$h_t$ summarizes all past tokens ⇒ unlimited context (beats $n{-}1$). Param sharing = time-translation invariance.

Issue — vanishing gradients. $\partial\mathcal L/\partial h_0=\prod_t\partial h_t/\partial h_{t-1}\to 0$ when $\|W_h\|_2<1$; early context forgotten. Also: strictly sequential.

LSTM fix. Gated additive cell state:

f_t,i_t,o_t = σ(W_{·}[h_{t-1},x_t]+b_{·})
c̃_t = tanh(W_c[h_{t-1},x_t]+b_c)
c_t  = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t    (additive!)
h_t  = o_t ⊙ tanh(c_t)

Addition ⇒ gradient highway $\partial c_T/\partial c_t\approx\prod_\tau f_\tau\approx$ const if $f\approx1$.

Forget gate permanently 1 ⇒ LSTM becomes? An unbounded accumulator that never forgets. The forget gate enables selective, bounded memory.

4. Seq2Seq

Key idea. Encoder–decoder for variable-length → variable-length (MT, summarization). Encoder RNN compresses source into a single context vector; decoder RNN generates autoregressively conditioned on it.

Encoder: h_1..h_n over x_1..x_n
         c = h_n      (B,h)  FIXED SIZE
Decoder: P(y_t | y_{<t}, c)  autoregressive

Training. Teacher forcing: feed gold $y_{t-1}$, not model output, so each step is an independent classification.

Issue — bottleneck. Entire source compressed into one fixed vector $c$. Long sequences suffer catastrophic forgetting in the encoder.

Next step. Let the decoder pull from all encoder states, not just the last ⇒ attention.

Doesn't making $h$ huge fix the bottleneck? No — it's information-theoretic. A fixed-size vector has bounded capacity regardless of dimension.

5. Attention (Bahdanau, 2015)

Key idea. At every decoder step, build a fresh context as a weighted sum of all encoder states. Weights come from a learned compatibility score between current decoder state and each encoder position.

e_{t,s} = vᵀ tanh(W_h·h^d_{t-1} + W_s·h^e_s)  additive
α_{t,s} = softmax_s(e_{t,s})                  Σ_s α=1
c_t     = Σ_s α_{t,s} · h^e_s                 dynamic ctx
e_t:(B,n)  α_t:(B,n)  c_t:(B,h)

What it gives. (i) No fixed bottleneck — capacity scales with source length. (ii) Interpretable soft alignment $\alpha$. (iii) Direct gradient path decoder→every encoder position.

Still limited. Encoder/decoder still recurrent ⇒ $O(n)$ sequential steps. Next leap: drop recurrence entirely, keep only attention → Transformer.

Cross-attn cost $O(n\cdot m)$; decoder self-attn cost at inference? $O(n^2)$ as $n$ grows — motivates KV-caching.

7. Pretraining & Transfer Learning

Key idea. Learn a strong prior over language from unlabeled text, then shift toward a task by fine-tuning. Same weights; contextual embeddings finally fix the polysemy problem of Word2Vec/GloVe.

BERT — Masked LM. Mask ~15% of tokens, predict originals with bidirectional context. $\mathcal L_{\text{MLM}}=-\sum\log P(w_{\text{mask}}\mid\text{full ctx})$. Encoder-only; classification/QA, not generation.

GPT — Causal LM. Predict $w_t$ from $w_{

Representation hierarchy (probing):

  • early: morphology, POS, surface form
  • middle: syntax, named entities
  • late: semantics, task-specific features
Why can't you pretrain BERT with a causal objective? Bidirectional attention sees the target token ⇒ trivial copying, no useful representation. MLM hides the target, forcing genuine contextual inference.

8. Text Generation: Training & Decoding

Training — Teacher Forcing.

for t in 1..T:
  input  = gold y_{t-1}      (NOT model's pred)
  target = y_t
  loss   = −log P(y_t | gold prefix)

Exposure bias. Train-time always sees a gold prefix; inference conditions on its own (possibly wrong) outputs ⇒ train/test mismatch, errors compound.

Decoding.

Greedy:    ŷ_t = argmax P(y_t|y_{<t})     fast, myopic
Beam(k):   top-k hypotheses per step     ↑BLEU, repetitive
Sampling:  y_t ~ P(·|y_{<t})             diverse, incoherent
Top-k:     sample from top-k tokens
Top-p:     smallest set Σp≥p             (nucleus)
Temp τ:    P'(y) ∝ P(y)^{1/τ}
           τ→0 = greedy, τ→∞ = uniform
Beam search maximizes BLEU but often produces worse text by humans — why? Beam maximizes $\log P(Y)$, favoring short/generic/high-prob completions. Human preference rewards fluency/informativeness not captured by likelihood.

6. Transformer — Shapes at Every Stage

Key idea. Drop recurrence entirely. Every token attends to every other token in parallel. Sequential depth $O(1)$, compute $O(n^2)$.

Attention — core formula. $\text{Attention}(Q,K,V)=\text{softmax}(QK^\top/\sqrt{d_k})\,V$. $Q$ = "what I'm looking for", $K$ = "what I advertise", $V$ = "what I actually give".

Why 3 projections if $Q,K,V$ all start from the same $x$? Without them the model can't learn the three distinct roles — and a token's dot product with itself always dominates, so every token would mostly attend to itself.

Why $\div\sqrt{d_k}$? In high dimensions dot products grow large ⇒ softmax saturates to near one-hot ⇒ gradients vanish. Scaling keeps magnitudes stable.

Shape flow — single head

input x       [B, S, H]
query_proj    [B, S, H]
key_proj      [B, S, H]
value_proj    [B, S, H]
attn_scores   [B, S, S]   Q·Kᵀ
attn_weights  [B, S, S]   softmax
output        [B, S, H]   weights·V

B=batch, S=seq_len, H=hidden_dim.

Shape flow — multi-head

[B, S, H]
  → .view(B,-1,nH,hD)   [B, S, nH, hD]
  → .transpose(1,2)     [B, nH, S, hD]

Q·Kᵀ                    [B, nH, S, S]
softmax(dim=-1)         [B, nH, S, S]
weights·V               [B, nH, S, hD]

  → .transpose(1,2)     [B, S, nH, hD]
  → .contiguous()
  → .view(B,-1,H)        [B, S, H]
out_proj                 [B, S, H]

nH=num_heads, hD=head_dim=$H/nH$.

Key operations — gotchas

.view(-1,...) − $-1$ infers a dim; passing seq_len directly also works.

.transpose(a,b) − symmetric: $(1,2)\equiv(2,1)$; $(-2,-1)\equiv(-1,-2)$.

.contiguous() − transpose only changes strides, not memory. .view() requires contiguous memory — omitting this crashes.

softmax dim=-1 − normalises over $K$ positions for each $Q$. dim=-2 would normalise over $Q$ — meaningless.

head_dim $=$ hidden_dim $//$ num_heads — must divide evenly (assert in __init__).

Why multi-head? One head captures one relationship at a time; multiple heads let the model attend to syntax, semantics, coreference etc. simultaneously. Specialisation is emergent — nothing enforces it.

Cross-attn mask is rectangular $[S_{\text{tgt}}\times S_{\text{src}}]$ because $Q$ comes from decoder (tgt) and $K,V$ from encoder (src). Self-attn masks are always square.

Decoder mask = causal AND pad. Only attend if the position is both a real token and not in the future.

Causal (S=4):    k0 k1 k2 k3
          q0  [  T  F  F  F ]
          q1  [  T  T  F  F ]
          q2  [  T  T  T  F ]
          q3  [  T  T  T  T ]        torch.tril(torch.ones(S,S,bool))

Self-attn vs cross-attn

self (encoder) − $Q,K,V$ all from $x$; every token sees all others.

self (decoder) − $Q,K,V$ from $x$, but causal mask hides future.

cross (decoder) − $Q$ from decoder $x$; $K,V$ from enc_output — decoder queries attend to encoder.

Why does the same model work in train (full tgt at once) and inference (one token at a time)? The causal mask simulates sequential generation during parallel training — they are identical computationally.

Encoder layer forward

x = embedding(src) * √H            [B,S,H]   scaling balances embeddings vs pos_enc
x = x + pos_encoding(0..S-1)       [B,S,H]   broadcast over batch; without this, attention is order-agnostic
for layer in layers:
    attn_out,_ = self_attn(x,x,x)  [B,S,H]   x,x,x = self-attention; _ discards weights
    x = norm1(x + attn_out)        [B,S,H]   residual + layernorm
    ff = linear2(relu(linear1(x))) [B,S,H]   FFN: H → intermediate_size → H
    x = norm2(x + ff)              [B,S,H]   residual + layernorm

Decoder — final projection

logits = out_proj(x)    [B, S_tgt, vocab_size]
# training:  cross_entropy(logits, target_ids)
# inference: argmax(logits[:,-1,:]) or sample → next token id

attn_weights are overwritten each layer — only the last decoder layer's weights are returned. Useful for visualisation, not needed for the forward pass.

Residuals, LayerNorm & Position

Residuals. Without them, each layer must reconstruct the original signal from scratch plus learn — very hard in deep nets, and gradients vanish. Residuals let each layer learn only the delta.

LayerNorm. Normalises activations across the hidden dim per token, independently. Stabilises training in deep stacks. Applied after the residual add.

FFN role. Attention mixes information across positions; FFN ($d\to4d\to d$ with GeLU) transforms each position independently — the per-token nonlinear computation.

Positional encoding. Attention is permutation-equivariant — without PE the model has no sense of order. $\text{PE}(p,2i)=\sin(p/10000^{2i/d})$, $\cos$ for odd $i$. Add, don't concat — keeps $d$ constant.

Shuffle tokens and their PEs together ⇒ output identical. The model only knows relative position, not absolute index.
Self-attention has no recurrence and no convolution — how does it know token order? It doesn't. PE must be injected; the architecture is permutation-equivariant by default.

9. REINFORCE, RLHF & DPO

Why RL? CLM optimizes next-token likelihood; human preferences (helpful, harmless, honest) are not predictable from MLE alone and not differentiable through discrete samples ⇒ policy gradient.

REINFORCE. Treat LM as policy $\pi_\theta(y\mid x)$. For scalar reward $r(x,y)$: $\nabla_\theta\mathbb{E}_{y\sim\pi_\theta}[r]=\mathbb{E}[r(x,y)\nabla_\theta\log\pi_\theta(y\mid x)]$. High variance ⇒ baseline $b$.

RLHF pipeline.

  • SFT — fine-tune on human demonstrations.
  • Reward model $r_\phi$ on pairs $y^w\succ y^l$ (Bradley–Terry): $\mathcal L_{\text{RM}}=-\mathbb E[\log\sigma(r_\phi(x,y^w)-r_\phi(x,y^l))]$.
  • PPO: $\max_\theta\,\mathbb E_{\pi_\theta}[r_\phi]-\beta\,\text{KL}[\pi_\theta\|\pi_{\text{ref}}]$.

Why KL? Without it, $\pi_\theta$ exploits $r_\phi$'s blind spots — "reward hacking" — drifting to OOD text that scores high but is bad.

DPO. Closed-form reparam removes explicit RM and RL loop: $\mathcal L_{\text{DPO}}=-\mathbb E[\log\sigma(\beta\log\tfrac{\pi_\theta(y^w)}{\pi_{\text{ref}}(y^w)}-\beta\log\tfrac{\pi_\theta(y^l)}{\pi_{\text{ref}}(y^l)})]$.

Why can't you skip SFT and run PPO on a raw pretrained model? It doesn't follow instructions; the RM is trained on instruction-following preferences; a near-random policy gives no useful gradient signal. SFT puts the policy where the RM is informative.

10. LLMs: ICL, Instruction Tuning, Post-training

In-Context Learning (ICL). Task specified entirely via prompt. Zero gradient updates.

Prompt = [demo_1, demo_2, ..., demo_k, query]
Model completes query — no parameter change.

Mechanistic views: attention over demos behaves like implicit gradient descent in activation space; demos form a task vector that shifts the residual stream into a task-relevant subspace.

Instruction tuning. Fine-tune on $\{(\text{instruction},\text{response})\}$ pairs. Updates weights; generalizes zero-shot to unseen task types. Unlike ICL, the capability is baked into the model, not re-invoked each prompt.

Full post-training pipeline.

Pretrained LM
  → SFT (instruction following)
  → Reward Model (human preferences)
  → RLHF / DPO (alignment)
  → Red-teaming + safety eval
ICL accuracy is robust to wrong labels in demonstrations — what does this reveal? The model uses demos mainly to identify task format and input distribution, not to learn input→output. The pretraining prior dominates the label signal.
Why does RLHF often make models less calibrated (sycophantic)? The RM rewards confident, agreeable answers; the KL penalty limits but can't prevent distributional drift; human raters often prefer a confident wrong answer over an uncertain correct one.
