Sparse vs Dense Representations

Sparse (one-hot): $\mathbf{e}_w \in \{0,1\}^{|V|}$, $|V| \approx 10^5$ — always orthogonal

Dense: $\mathbf{e}_w \in \mathbb{R}^d$, $d \ll |V|$ — similarity via dot product / cosine

Distributional hypothesis: words appearing in similar contexts have similar meanings → geometry encodes semantics
Sparse: $\cos(\text{cat}, \text{dog}) = 0$ always — no generalization across vocabulary
If two words never co-occur but appear in identical contexts, can one-hot capture their similarity? No — they remain orthogonal regardless of any evidence.
Word2Vec

CBOW — predict center $w_t$ from context $\{w_{t-k},\ldots,w_{t+k}\}$

input: avg(E[w_{t-k}],...,E[w_{t+k}]) ∈ ℝᵈ predict: softmax(W · avg) → P(w_t)

Skip-gram — predict each context word $w_{t+j}$ from center $w_t$, $j \in [-k,k]\setminus\{0\}$

per center word: generate k training pairs → k×more updates for rare words than CBOW

Negative sampling: replace $\text{softmax}_{|V|}$ with binary classification over $k$ noise samples → $\mathcal{O}(k)$ instead of $\mathcal{O}(|V|)$

Linear analogy: $\mathbf{e}_{\text{king}} - \mathbf{e}_{\text{man}} + \mathbf{e}_{\text{woman}} \approx \mathbf{e}_{\text{queen}}$ — meaning lives in vector differences
CBOW averages context embeddings — what information is destroyed? Word order and individual identity (bag-of-words over window). Skip-gram has no such averaging.
GloVe

Combines global co-occurrence statistics $X_{ij}$ (like LSA) with dense prediction (like word2vec):

J = Σᵢⱼ f(Xᵢⱼ)(wᵢᵀw̃ⱼ + bᵢ + b̃ⱼ − log Xᵢⱼ)² f(x) = (x/x_max)^α if x < x_max, else 1 ↑ downweights very frequent co-occurrences
GloVe explicitly factorizes the log co-occurrence matrix. Word2Vec implicitly factorizes the shifted PMI matrix — equivalent in theory, different inductive biases in practice.
Both Word2Vec and GloVe are "static" — one vector per word. What problem does this create? Polysemy: "bank" gets a single averaged embedding for all senses.
N-gram Language Models (Fixed Context)

Markov assumption truncates history to $n{-}1$ words:

P(wₜ | w₁..wₜ₋₁) ≈ P(wₜ | wₜ₋ₙ₊₁..wₜ₋₁) P̂(wₜ|ctx) = C(ctx, wₜ) / C(ctx) [MLE] Perplexity: PP(W) = P(W)^{-1/N}
  • Smoothing (Laplace, Kneser-Ney) handles zero counts
  • Kneser-Ney exploits continuation probability
Sparsity of high-order n-grams; no cross-word generalization (cat ≠ dog even if synonyms); context hard-limited to $n{-}1$ tokens
→ Neural LMs: shared embedding parameters enable generalization across similar words
Perfect n-gram smoothing still can't generalize across synonyms — why? No distributed representation; each word is an atomic symbol; smoothing only redistributes mass, doesn't create similarity structure.
Recurrent Neural Networks (RNN)
hₜ = tanh(Wₕ·hₜ₋₁ + Wₓ·xₜ + b) hₜ ∈ ℝʰ P(wₜ₊₁) = softmax(W_out·hₜ)
for t in 1..T: x_t: (B, d) # token embedding h_t: (B, h) # hidden state # same W_h, W_x reused at every step
Hidden state $h_t$ theoretically encodes all previous tokens — unlimited context vs n-gram's $n{-}1$. Parameter sharing across time = translation invariance.
Vanishing gradient: $\frac{\partial\mathcal{L}}{\partial h_0} = \prod_{t=1}^T \frac{\partial h_t}{\partial h_{t-1}} \to 0$ when $\|W_h\|_2 < 1$ — early context forgotten. Sequential computation prevents parallelism.
Long Short-Term Memory (LSTM)
fₜ = σ(Wf·[hₜ₋₁,xₜ]+bf) [forget gate] iₜ = σ(Wᵢ·[hₜ₋₁,xₜ]+bᵢ) [input gate] c̃ₜ = tanh(Wc·[hₜ₋₁,xₜ]+bc) cₜ = fₜ⊙cₜ₋₁ + iₜ⊙c̃ₜ [cell — additive!] oₜ = σ(Wo·[hₜ₋₁,xₜ]+bo) [output gate] hₜ = oₜ⊙tanh(cₜ)
Cell state uses addition, not multiplication → gradient highway: $\frac{\partial c_T}{\partial c_t} \approx \prod_\tau f_\tau$ ≈ constant when $f \approx 1$. Solves vanishing gradient of RNN.
If the forget gate always outputs 1, what does LSTM reduce to? An accumulator that never forgets — cell state grows unboundedly. The forget gate is what enables selective, bounded memory.
Still sequential (no parallelism) + encoder-decoder bottleneck in seq2seq
Seq2Seq

Encoder-decoder for variable-length → variable-length (MT, summarization)

Encoder: RNN over source x₁..xₙ output: c = h_T # (B, h) — FIXED VECTOR Decoder: RNN conditioned on c P(yₜ | y₁..yₜ₋₁, c) → autoregressively generates y₁..y_m
Bottleneck: entire source sequence compressed into fixed-size $c = h_T$. Capacity is bounded — long sequences suffer catastrophic forgetting in the encoder.
Doesn't making $h$ much larger fix the bottleneck? No — it's information-theoretic. A fixed-size vector has bounded capacity regardless of dimensionality; the issue is compression, not size.
→ Attention: compute a separate, dynamic context per decoder step
Attention (Bahdanau, 2015)

At each decoder step $t$, score all encoder hidden states $\{h^e_s\}_{s=1}^n$:

eₜₛ = vᵀ tanh(Wₕ·hᵈₜ₋₁ + Wₛ·hᵉₛ) [additive score] αₜₛ = softmax_s(eₜₛ) [attention weights] cₜ = Σₛ αₜₛ · hᵉₛ [dynamic context]
e_t: (B, n) # energy over n source positions α_t: (B, n) # weights, Σ_s α_{t,s} = 1 c_t: (B, h) # weighted sum of encoder states
$\alpha_{t,s}$: soft alignment — how much decoder step $t$ attends to source position $s$. No bottleneck + interpretable alignment matrix.
Cross-attention is $O(n \cdot m)$. What is the complexity of self-attention in a decoder at inference? $O(n^2)$ as sequence grows — motivates KV caching (store computed K,V, only compute new query).

Self-Attention (Scaled Dot-Product)
Q = X·W_Q, K = X·W_K, V = X·W_V Attn(Q,K,V) = softmax( Q·Kᵀ / √dₖ ) · V
X: (B, n, d) # input sequence W_Q,W_K: (d, dₖ) # projection matrices W_V: (d, dᵥ) Q, K: (B, n, dₖ) # queries & keys V: (B, n, dᵥ) # values Q·Kᵀ: (B, n, n) # pairwise attention logits out: (B, n, dᵥ) # attended representations
Scale by $1/\sqrt{d_k}$: without it, dot products grow as $O(d_k)$ → softmax saturates → near-zero gradients. All pairs computed in parallel: $O(n^2)$ space, $O(1)$ sequential steps.
Self-attention has no recurrence and no convolution — how does it know token order? It doesn't. Positional encodings must be injected; the architecture is permutation-equivariant by default.
Multi-Head Attention
headᵢ = Attn(X·WᵢQ, X·WᵢK, X·WᵢV) i=1..h MHA = Concat(head₁,...,headₕ) · W_O
each headᵢ out: (B, n, dᵥ) dᵥ = d/h after Concat: (B, n, h·dᵥ) = (B, n, d) after W_O: (B, n, d) # h heads at d/h dims ≈ 1 head at d dims (same FLOPs)
Each head attends to different relationship types (syntax, coreference, position). Different subspaces independently, then merged.
Transformer Block — Shapes at Each Stage
Input X: (B, n, d) │ ├─ LayerNorm(X) → (B, n, d) ├─ MHA → (B, n, d) ← parallel over n ├─ + residual → (B, n, d) ← gradient highway │ ├─ LayerNorm → (B, n, d) ├─ FFN: W₁(d→4d)+GeLU, W₂(4d→d) │ → (B, n, d) ← per-token, no mixing └─ + residual → (B, n, d)

Pos. encoding: $\text{PE}(p,2i)=\sin\!\left(\tfrac{p}{10000^{2i/d}}\right)$, $\cos$ for odd $i$

Enc.: full attention mask. Dec.: causal lower-triangular mask.

The FFN expands to 4d then contracts. What role does it play that attention cannot? Attention mixes information across positions; FFN transforms each position independently — it is the per-token "memory" / nonlinear computation.
Pretraining & Transfer Learning

Masked LM — BERT: mask 15% of tokens, predict originals → bidirectional context

Causal LM — GPT: predict $w_t$ given $w_{<t}$ → left-to-right, generative

L_MLM = −Σ log P(w_mask | full_bidirectional_ctx) L_CLM = −Σₜ log P(wₜ | w₁,...,wₜ₋₁)

Representation hierarchy (probing):

  • Early layers: morphology, POS, surface form
  • Middle layers: syntax, named entities
  • Late layers: semantics, task-specific features
Pretraining = learning a prior over language structure from unlabeled data. Fine-tuning = shifting that prior toward a task. Same weights; same contextual embeddings solve the polysemy problem of Word2Vec/GloVe.
Why can't you pretrain BERT with a causal LM objective? Bidirectional attention sees the future token it must predict — trivially solved by copying, no useful representation learned. The masking forces genuine contextual inference.
Text Generation: Training & Decoding

Training — Teacher Forcing:

for t in 1..T: input: gold y_{t-1} # NOT model's prediction target: y_t loss: −log P(y_t | gold prefix)
Exposure bias: at inference, model conditions on its own (possibly wrong) outputs — train/test distribution mismatch. Errors compound.

Decoding strategies:

Greedy: ŷₜ = argmax P(yₜ|y
Beam search often scores higher in BLEU than sampling but produces worse text by human judgment — why? Beam maximizes $\log P(Y)$, which favors short, generic, high-probability completions. Human preference rewards fluency and informativeness not fully captured by likelihood.
RLHF (PPO) & DPO

Problem: CLM optimizes token likelihood; human preferences (helpfulness, safety) are not predictable from MLE alone.

Step 1 — SFT: fine-tune on human demonstrations

Step 2 — Reward Model: train $r_\phi(x,y)$ on preference pairs $(y_w \succ y_l)$:

L_RM = −𝔼[ log σ( r_φ(x,yʷ) − r_φ(x,yˡ) ) ] [Bradley-Terry]

Step 3 — PPO:

max 𝔼_{π_θ}[ r_φ(x,y) ] − β · KL[ π_θ ‖ π_ref ] ↑ maximize reward ↑ stay close to SFT
KL penalty prevents reward hacking: without it, $\pi_\theta$ exploits blind spots of $r_\phi$, generating OOD text that scores high but is actually bad.

DPO — bypasses explicit RM, directly optimizes preference objective:

L_DPO = −𝔼[log σ(β log π_θ(yʷ)/π_ref(yʷ) − β log π_θ(yˡ)/π_ref(yˡ))]
Why can't you skip SFT and PPO directly from a pretrained model? The pretrained model doesn't follow instructions; the RM was trained on instruction-following preferences; a random policy provides no useful gradient signal and wastes compute.
In-Context Learning (ICL)

Task specified entirely via prompt. Zero gradient updates to weights.

Prompt = [demo₁, demo₂, ..., demoₖ, query] Model completes query — no parameter change

Mechanistic views:

  • Meta-learning: attention over demos ≈ implicit gradient descent in activation space
  • Task vector: demos shift residual stream into a task-relevant subspace
ICL performance is robust to wrong labels in demonstrations — what does this reveal? The model uses demos to identify task format and input distribution, not to learn the input→output mapping. Pretraining prior dominates label signal.
Instruction Tuning & Post-Training

Instruction tuning: fine-tune on $\{(\text{instruction}, \text{response})\}$ pairs → better zero-shot generalization across unseen task types

Instruction tuning ≠ ICL: IT updates weights and generalizes to new task types; ICL uses context and stays within pretrained capabilities. Both expose the model to task format, different mechanisms.

Full post-training pipeline:

Pretrained LM → SFT (instruction following) → Reward Model (human preferences) → RLHF / DPO (alignment) → Red-teaming + safety evaluation
RLHF can make models more helpful but less calibrated (sycophantic, overconfident) — structural reason? RM rewards confident agreeableness; KL penalty limits but doesn't prevent distributional shift; human raters may prefer confident wrong answers over uncertain correct ones.
Full Concept Chain
n-gram: fixed context, sparse, no generalization ↓ embeddings + recurrence RNN: unlimited context; vanishing gradient ↓ gated additive cell state LSTM: stable gradients; sequential bottleneck ↓ dynamic context per decoder step Seq2Seq + Attention: no bottleneck; O(n) steps ↓ full self-attention, parallelism Transformer: O(1) depth, scalable to large data ↓ scale + unlabeled pretraining BERT / GPT: contextual representations (fix polysemy) ↓ human feedback signal RLHF / DPO: aligned, instruction-following LLM ↓ task format in context ICL: task adaptation without weight updates
